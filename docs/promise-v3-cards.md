# 一張支票 v3：範例卡（草稿，作者確認後才改程式）

原則：卡片是「有內容的兩難」，人只是把問題帶來；左右兩邊都說得通、都有代價，代價要在之後某張具體的卡被提起。卡片裡不寫真實路線名、社區名、人名、政黨，只在「參考」欄附真實出處。

## 上任時「前任的桌上」：每局隨機抽 2～3 條線，各在不同階段

### A. 前任留下、已經在動工的線（做好是前任的功勞，出事是你挨罵）

**1. 料工雙漲**
- 主計處長：「前任那條在蓋的線，料工雙漲，要追加一百多億。中央說要等修正計畫核定，才撥一部分。」
- ← 送議會追加預算：工程照走。之後預算關卡議員會開條件（交換），審不過就停工。
- → 減項：一座車站改成「預留站」，先不蓋。工期、預算保住。之後那一站的里長每年都來陳情，通車典禮有人舉牌「我們的站呢？」
- 參考：某條捷運與另兩項計畫修正後要增加 756.85 億元，其中 427 億元要等中央核定修正計畫後才撥付，原因是料工雙漲、缺工缺料（中央社 2023/8/18 https://www.cna.com.tw/news/afe/202308180168.aspx ；行政院 https://www.ey.gov.tw/Page/9277F759E41CCD91/5877caec-6f03-4248-8b0f-2b80b4c8a521 ）

**2. 工地出事了**（語氣嚴肅，不開玩笑）
- 局長：「潛盾機隧道工地出事，一位工人受重傷。勞檢處要求事故工區停工。」
- ← 全線停工總體檢：延期半年，追加預算的帳單更長。之後安全紀錄好，通車時沒人能翻這筆帳。
- → 只停事故工區，其他照進度：時程保住。之後如果再出一次事，議會要你到場專案報告，記者會翻出這一次。
- 參考：某條捷運隧道工地潛盾機意外，市府要求事故工地停工、提出原因分析與改善對策才能復工（台灣英文新聞 https://www.taiwannews.com.tw/zh/news/4300022 ；公視 https://news.pts.org.tw/article/780994 ）

**3. 原本說好的完工年**
- 記者：「這條線原本說好幾年前就要完工，現在又延。市民問：到底誰負責？」
- ← 「這是前任的規劃」：當下民意不掉，但前任同黨的議員開始在預算上找麻煩。
- → 「我負責，公布新時程」：當下民意掉。之後新時程準時到了，這一句會被翻出來加分；沒到，記者會拿這段影片重播。
- 參考：某條捷運 2010 年核定，第一期原訂 2018 年完工，因車站出口用地未取得、都市計畫變更未過、財務計畫被退回修正而延後（自由時報 https://news.ltn.com.tw/amp/news/local/paper/754501 ；公視 https://news.pts.org.tw/article/820556 ）

### B. 這一任要拍板的線

**4. 路線兩案**
- 局長：「路線有兩案。A 走老社區，人多、運量高，但要拆不少房子；B 沿河濱，便宜又快，但車站離住家遠。」
- ← A 案：之後「用地取得」那關多兩張卡（拆遷戶、說明會抗議），民意先掉。通車後運量好。
- → B 案：可行性研究和綜合規劃都快。通車後運量只有預估的六成多，脆上叫它「河濱觀光線」，審計報告點名。
- 參考：某條輕軌通車後運量達成率約只有預期目標的 65%，部分車站遠離人口稠密區（新北市捷運局資料 https://www.dorts.ntpc.gov.tw/cdn/file/20260821/95396612-4f8a-40cc-9e2d-fd55818f57f4.pdf ；聯合報 https://udn.com/news/story/7323/9656849 ）；學者指規劃時常「高估運量、低估成本」（遠見 https://www.gvm.com.tw/article/122658 ）

**5. 高架還是地下**
- 科長：「高架便宜一半、快三年，但沿線住戶窗外就是軌道。地下要穿過民宅底下，貴很多，還要給被穿越的人補償。」
- ← 高架：省錢、快。之後沿線自救會抗議出土段、噪音振動，說明會要多開兩場。
- → 地下：之後財政壓力大，其他主線的預算被排擠；穿越的土地要用容積獎勵回饋，都發局會來找你。
- 參考：某條環狀線段由地下改高架，出土段被沿線廠商抗議施工振動、道路縮減（新頭殼 https://newtalk.tw/news/view/2021-03-19/551337 ；公視 https://news.pts.org.tw/article/520620 ）；另一段地下穿越民宅，市府訂地下穿越容積獎勵、劃都更地區回饋（臺北市都發局說明會紀錄 https://www.udd.gov.taipei/assets/hrBaPEUiAdVbRmx86cezDd/attachs/說明會會議紀錄(第1場).pdf ）

**6. 要不要等中央**
- 交通部官員：「地方財力級次調整了，貴府的財務計畫要重算自償率和中央補助比例。」
- ← 照意見重算再送：慢一年，但中央補助比例確定。
- → 市府先自籌，不等：快。之後主計處長說其他主線的預算要排後面，議會質詢「市府舉債蓋捷運」。
- 參考：某市捷運延伸案因地方財力分級調降，交通部要求依新級次修正財務評估、重算自償率與中央補助比例（聯合報 https://udn.com/news/story/7325/9381909 ）

**7. 跨市誰先做**
- 鄰市副市長：「跨市那條線，我們想先做我們那一段，你們那段之後再說。」
- ← 同意鄰市先做：鄰市那段先動工。你這一段的里長問「我們的呢？」，你的任期內大概輪不到。
- → 堅持全線一起：兩市意見不同，中央以「地方意見不一致」擱置，兩邊都卡。
- 參考：某條跨市捷運，一市主張全線一起做、另一市主張東段先蓋，後來東段由另一個計畫獨立成案先核定，市區段綜合規劃送審後仍未核定（新頭殼 2021 https://newtalk.tw/news/view/2021-11-16/667186 ；中央社 https://www.cna.com.tw/news/firstnews/202111160109.aspx ；自由時報 https://news.ltn.com.tw/news/life/paper/1484939 ）

### C. 前任說要做、其實只有一頁簡報的線

**8. 一頁簡報**
- 科長：「前任說要做的那條線，我們翻遍檔案，只找到一頁簡報。沒有路網評估，沒有運量推估。」
- ← 從路網評估重來：四年大概只做得到可行性研究。結局寫「你幫下下任市長打好了地基」。
- → 先開記者會宣布「啟動」：民意立刻漲。之後交通部要求先補路網評估，記者翻出你的記者會影片。
- 參考：交通部要求地方先送「整體路網評估」才審個別路線的可行性研究（新北市捷運局資料 https://www.dorts.ntpc.gov.tw/cdn/file/20211025/1bbd43c4-a0d3-4c20-850e-6f18763b2b5f.pdf ）；某市「多線齊發」被議員指出多數還在可行性研究階段（NOWnews https://www.nownews.com/news/6691771 ）

### D. 市區段沿線社區意見分裂

**9. 社區一半要、一半不要**
- 里長：「我們社區一半的人要站，一半的人怕施工、怕樹被砍、怕老房子裂掉。」
- ← 改線走旁邊的大路：這個社區不吵了，但車站離他們遠；另一條路的居民開始組自救會。
- → 照原路線，多開說明會：環評和都市計畫那關卡好幾年。沿線房價先漲，脆上兩派吵起來。
- 參考：某條捷運經過老社區，居民以路窄、屋老、怕鄰損與砍樹反對，路線改走另一條路的替代方案也引起爭議，多年未推（TVBS https://news.tvbs.com.tw/life/911604 、https://news.tvbs.com.tw/life/1045031 ；公展前座談會紀錄 https://udd.gov.taipei/assets/mFVftVDWsHqw9Q4BMipDFb/attachs/1131108-民汐線公展前座談會紀錄(松山場).pdf ）

**10. 機廠徵收**
- 地主自救會（透過里長轉達）：「徵收價太低了。動工典禮那天，我們會去。」
- ← 改聯合開發、讓地主分回樓地板：之後市府少收一筆開發收益，主計處長來要錢；議員說是他喬的，你欠他人情。
- → 依法一般徵收：動工典禮外面百人抗議上新聞。下一條線的說明會，居民一開口就提這件事。
- 參考：某機廠動工典禮當天，地主不滿徵收與聯開分配，自救會百餘人在會場外抗議（自由時報 https://news.ltn.com.tw/amp/news/life/paper/607800 ）；另一輕軌機廠以一般徵收取得約七公頃，地主組自救會抗爭（蕃薯藤 https://n.yam.com/Article/20190714848553 ）

## 關係後果規則（草案）
1. 每段關係只記一件具體的事（「你拒絕了方議員的活動中心」），之後一定會在一張具體的卡上被提起，當場改變那張卡的選項或代價。
2. 記恨：議員在下一次預算關卡多一個「先凍結三成」的條件；里長在說明會帶人來，那關要多推一下。
3. 人情：對方之後要你在別的地方讓步（例：一站改設在他的選區），不還就轉成記恨。
4. 功勞：被搶走的那一關，過關時民意不漲；連任時「你做了什麼」少一項可以講。
5. 結局只列真的影響過什麼（「方議員因為活動中心，凍結你的捷運預算三成，延了兩季」）；沒影響過的關係不列。
